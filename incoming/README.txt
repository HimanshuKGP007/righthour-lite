Live feed folder.
Drop a CSV in the same format as the steel file (date, Usage_kWh, power factor columns) into this folder.
The app picks it up while Live mode is on, and adds the readings to the meter history.
A file that cannot be read is skipped, and the app shows why.
Re-saving a file with the same dates replaces the old readings for those dates.
A real meter feed would write its files here, or replace this folder with a direct link.
